# 2. 背景与研究动机

## 2.1 为什么要写这篇综述？

因为 STEM 领域正在发生一个转变：

> 过去：人看图、选区域、解释局部结构。  
> 现在：仪器产生海量多模态数据，需要自动提取结构、化学、电子、应变、场分布等信息。  
> 未来：显微镜本身可能变成“自驾驶实验平台”。

文章强调，现代 STEM 不只是二维图片，而是可以同时获得 ADF、ABF、EELS、EDS、4D-STEM 等多种信号；这些信号包含厚度、成分、结构、局部电磁场、能量损失、动量信息等。问题是：==**数据越来越复杂，靠人工看图已经不够了。**==

## 2.2 领域发展背景

主要有三条技术线推动了这篇文章的出现：

第一，**像差校正**让 STEM 可以稳定看到原子柱甚至单原子。原子位置、强度、形状已经可以被提取成定量数据，而不是只作为图片展示。

第二，**探测器升级**带来了 4D-STEM、DPC、像素化探测器、多通道同步采集等新模式。数据维度从 2D 图像变成高维数据立方，必须依赖算法处理。

第三，**机器学习成熟**，可以做原子定位、缺陷分类、降噪、超分辨、谱图分解、主动实验、自动调参，甚至与 DFT、分子动力学、相场模型结合，去==学习材料背后的物理机制。==

## 2.3 应用场景与科学问题

这篇文章关心的不是单一任务，而是==一整套 STEM-AI 研究生态==：

|场景|科学问题|
|---|---|
|原子分辨 STEM 图像|原子在哪里？是什么元素？是否有缺陷？|
|EELS / EDS|局部化学成分、价态、电子结构如何变化？|
|4D-STEM|局部应变、电场、磁场、极化、对称性如何分布？|
|定量 STEM|图像强度能不能和模拟、厚度、成分对应起来？|
|缺陷与界面|缺陷如何形成、迁移、聚集？|
|自动实验|显微镜能不能自己找区域、调参数、优化成像？|
|原子制造|电子束能否定向移动原子、制造空位、掺杂原子？|

# 3. 方法与研究分类

这篇文章的分类逻辑不是“监督学习 / 无监督学习 / 强化学习”这种 AI 教科书分类，而是按照 **STEM 数据链条** 来组织：

> 成像方式 → 数据处理 → 定量结构提取 → 机器学习建模 → 物理解释 → 自动实验。

## 3.1 按 STEM 数据类型分类

|类别|数据形式|代表方法 / 模式|ML 主要作用|优点|局限|
|---|---|---|---|---|---|
|结构 STEM 图像|2D 原子图像|ADF、HAADF、ABF|原子定位、缺陷识别、图像分割、降噪|直观，适合原子柱识别|厚度、动力学散射、轻元素识别困难|
|EELS / EDS|谱图 / hyperspectral data|Core-loss、low-loss、phonon、plasmon|谱图降噪、成分分解、电子结构分析|同时给结构和化学信息|信噪比低，背景复杂，解释困难|
|q-EELS|动量分辨谱图|Momentum-resolved EELS|提取各向异性、声子/等离激元色散|能看能量-动量关系|空间分辨率和动量分辨率互相制约，信号弱|
|4D-STEM|每个扫描点一个衍射图|Ptychography、DPC、strain mapping|重建、去噪、场/应变/相位提取|信息量极高|数据量巨大，计算复杂|
|Beam engineering|特殊电子束|Vortex beam、Gaussian beam、Bessel beam、MIDI-STEM|优化束形、控制光学系统|可测量传统模式难以看到的物理量|仪器复杂，控制难度高|
|自动化 STEM|实时数据流|Bayesian optimization、RL、active learning|自动调参、自动选区、主动采样|走向 self-driving microscope|需要低延迟控制、开放接口、稳定硬件|

论文把 ADF/ABF/EELS/4D-STEM 看成不同信息通道：ADF/HAADF 适合看重元素原子柱，ABF 更适合轻元素，EELS 能提供局部化学与电子结构，4D-STEM 则通过像素化探测器在每个扫描点记录衍射信息。

| ML 任务           | 典型方法                                         | 在 STEM 中做什么            |
| --------------- | -------------------------------------------- | ---------------------- |

## 3.3 文章重点讲的几类方法

### A. 传统定量图像分析：从图像到原子坐标

经典路线是：

> 图像 → 找局部亮点 → 初始原子位置 → 高斯/点扩散函数拟合 → 原子坐标、强度、形状、不确定性。

这类方法适合 HAADF / Z-contrast 图像，因为亮点通常对应原子柱，强度大致和原子序数有关。但问题是：样品厚度、动力学散射、仪器不稳定都会导致亮点位置和真实原子位置不完全一致。文章明确指出，原子分辨 STEM 图像中的材料信息常常可以压缩成原子柱的位置、强度、形状及其不确定性。

### B. 多变量统计方法：PCA / NMF

主要用于 EELS / EDS 这种高维谱图数据。  
优点是简单、成熟、可解释，用来降噪和分解谱图很常见。

但文章也提醒：PCA 容易把“少数区域才出现的重要缺陷/界面信号”当成低权重成分删掉。这对材料研究很危险，因为最有意思的物理往往就在缺陷、界面、边缘这些少数区域。

### C. 深度学习：原子定位、缺陷识别、图像增强

CNN / U-Net 类方法适合做：

- 原子定位；
- 缺陷检测；
- 图像分割；
- 去噪；
- 超分辨；
- 化学识别；
- 局部结构跟踪。

对你现在做的 TEM/STEM 图像质量评价来说，这一类最直接相关。因为你的思路本质上就是：

> 固定一个原子定位模型，然后看不同退化图像会如何影响原子定位结果。

文章也引用了 TEMImageNet 和 AtomSegNet 相关工作，用于原子分割、定位、去噪和超分辨。

### D. 生成模型与表征学习：VAE / rVAE

这类方法不是只做分类，而是希望从图像中学到“低维结构变量”。  
例如 rVAE 可以把旋转、平移等无关因素剥离出来，帮助发现局部结构变化、化学演化路径、分子构件和反应路径。

这对材料研究很重要，因为很多时候我们不知道标签是什么，甚至不知道应该分几类。无监督/弱监督方法可以帮助发现隐藏结构。

### E. 物理约束 / 物理模型学习

文章非常强调：STEM + ML 不能停留在“看起来相关”，而应该走向“物理解释”。  
也就是说，机器学习不只是帮你识别缺陷，还要进一步回答：

- 缺陷为什么形成？
    
- 局部结构如何影响极化、应变、电子结构？
    
- 能否从观测到的原子构型反推相互作用势、力场、哈密顿量参数？
    
- 能否连接 DFT、分子动力学、相场模型？
    

文章提到，STEM 数据可以提供物理系统的微观状态，并用于和 Ising、Heisenberg 等格点模型或其他生成模型比较，甚至重建原子间力场。

# 4. 对比与总结

## 4.1 各类方法优点与局限

| 方法类别                       | 优点                     | 局限                      |
| -------------------------- | ---------------------- | ----------------------- |
| 传统原子定位 / 拟合                | 可解释，和物理量直接对应，适合做精确定量   | 对噪声、厚度、动力学散射敏感；需要人工设定模型 |
| PCA / NMF                  | 简单，适合 EELS/EDS 降噪和谱图分解 | 可能误删缺陷、界面等少数但重要的局部信号    |
| CNN / U-Net                | 对复杂图像鲁棒，适合分割、定位、缺陷识别   | 需要标注数据；跨材料、跨仪器泛化困难      |
| VAE / 表征学习                 | 可发现未知结构模式，适合无标签数据      | 潜变量解释不一定清楚，容易学到非物理因素    |
| Physics-based ML           | 能连接图像和材料机制，适合做高水平研究    | 需要物理先验、校准数据和不确定性建模      |
| Bayesian optimization / RL | 适合自动调参、自主实验            | 需要仪器控制接口、实时计算、稳定反馈      |
| 4D-STEM + ML               | 信息量巨大，可提取应变、电场、相位等     | 数据量大，计算重，标准化与复现困难       |

## 4.2 哪些方法在特定场景突出？

==如果目标是 **原子定位**：  
传统高斯拟合和 U-Net / AtomSegNet 类深度学习都重要。前者可解释，后者鲁棒。==

==如果目标是 **图像质量评价**：  
不能只看图像指标，应该看下游任务输出，例如原子定位误差、检测率、晶格间距稳定性、缺陷识别稳定性。

如果目标是 **EELS 谱图分析**：  
PCA / NMF 是基础工具，但要小心局部缺陷信息被当成噪声去掉。

==如果目标是 **自动实验**：  
Bayesian optimization、Gaussian process、reinforcement learning 是重点，因为它们可以在实验过程中决定下一步采哪里、怎么调参数。

如果目标是 **从图像走向物理机制**：  
需要把 STEM 量化结果和 DFT、MD、相场、格点模型结合，而不是只停留在分类准确率。

## 4.3 方法演化脉络

这篇文章隐含的演化逻辑可以概括为：

> ==看图 → 定量测量 → 机器学习识别 → 结构-性能关联 → 物理模型反演 → 自动化实验 → 原子级制造。

也就是从“人看图解释”走向“机器提取可量化结构”，再走向“机器根据实验数据学习材料物理”，最后走向“机器主动控制显微镜做实验”。

# 5. 趋势与未来方向

## 5.1 论文总结的未来方向

| 方向               | 含义                           |
| ---------------- | ---------------------------- |
| ==定量 STEM==      | 从漂亮图片变成可复现、可比较的定量数据          |
| 多模态融合            | 同时使用图像、EELS、EDS、4D-STEM、模拟数据 |
| Physics-based ML | 让模型输出能对应真实物理量，而不是黑箱分类        |
| 不确定性估计           | 每个原子位置、缺陷判断、谱图分解都要有置信度       |
| 自动化显微镜           | 自动调焦、自动找区域、自动决定下一步实验         |
| 非传统扫描路径          | 螺旋扫描、压缩感知、主动采样，减少剂量和时间       |
| 数据与元数据标准化        | 保存加速电压、会聚角、步长、驻留时间、束流、探测器参数等 |
| 开源软件生态           | 发展共享代码、共享数据、共享工作流            |

文章特别强调，STEM 实验要想复现，必须记录关键元数据，例如加速电压、会聚角、扫描步长、驻留时间、束流、探测器角度、EELS 能量范围、4D-STEM 探测器像素尺寸等。

## 5.2 当前主要挑战

1. **数据太大**：尤其是 4D-STEM，普通工作站和网络传输都可能成为瓶颈。
    
2. **缺少标准数据格式**：很多厂商数据格式封闭，不利于复现。
    
3. **元数据不完整**：没有仪器参数，后续很难复现实验。
    
4. ==**模型泛化困难**：一个显微镜/材料上训练的模型，不一定适用于另一个材料。==
    
5. **物理解释不足**：相关性不等于因果，ML 不能只给分类结果。
    
6. **仪器控制接口封闭**：要做自动实验，需要能实时控制扫描路径、束流、探测器和显微镜参数。
    
7. **束流损伤问题**：低剂量、高信噪比、实时分析之间存在矛盾。
    

==文章指出，目前还没有一个既足够开放、又能覆盖各种 STEM 实验、同时强制要求完整数据和元数据的通用 STEM 数据库，因此该领域非常需要面向复现的数据基础设施。==

# 6. 对你研究方向的启发：AI for Material + TEM 图像

这篇文章对你现在做的 **TEM/STEM 图像质量评价、原子定位、图结构构建** 很有直接启发。

## 6.1 最大启发：图像质量不能只看图像本身

你现在如果只用 SSIM、PSNR、SNR 去评价 TEM 图像质量，是不够的。  
这篇文章的思路更接近：

> ==图像质量 = 这张图能不能稳定、可信地支持后续材料分析。==

==对你来说，后续材料分析可以是：==

- 原子中心定位；
    
- 原子柱强度统计；
    
- 晶格间距测量；
    
- 缺陷检测；
    
- Delaunay graph 构建；
    
- 局部结构分类；
    
- 空位浓度统计；
    
- 应变场计算。
    

==所以你可以把图像质量评价定义成：

> ==`输入图像发生噪声、模糊、背景、扫描畸变后，下游原子定位和图结构分析结果是否仍然稳定。

这和你已经做的 “固定 AtomSegNet / 定位模型，看退化图像下定位精度、检测率、晶格稳定性变化” 是一致的。

## 6.2 你的研究可以形成一个清晰框架

可以整理成：

> ==TEM/STEM 图像 → 原子定位模型 → 原子坐标/强度 → 晶格/图结构 → 质量指标 → 物理一致性验证。

==对应指标可以包括：

| 层级    | 可用指标                                             |
| ----- | ------------------------------------------------ |
| 图像层   | SNR、背景强度、对比度、模糊程度                                |
| 原子定位层 | detection rate、localization precision σ、bias、漏检率 |
| 晶格层   | a/b 晶格间距稳定性、角度稳定性、局部畸变                           |
| 图结构层  | 邻接边稳定性、配位数稳定性、Delaunay graph 一致性                 |
| 缺陷层   | vacancy 识别稳定性、边缘/内部原子检测差异                        |
| 物理层   | 是否违反晶格周期性、键长范围、配位数、材料结构先验                        |

这比单纯“图像清不清楚”更像材料 AI 研究。

## 6.3 这篇文章给你的选题方向

我觉得最适合你的是下面这个题目方向：

> **面向原子定位与图结构分析的 TEM/STEM 图像质量评价方法**

更学术一点可以写成：

> **Task-driven quality assessment of atomic-resolution TEM/STEM images for robust atom localization and graph-based structure analysis**

核心创新不一定是发明一个新模型，而是建立一套评价框架：

1. 构造图像退化序列；
    
2. 固定原子定位模型；
    
3. 统计定位稳定性；
    
4. 构建原子图；
    
5. 评价图结构是否稳定；
    
6. 加入物理一致性约束；
    
7. 最后服务于缺陷识别或结构分类。
    

这条路线非常贴近这篇综述提出的 “quantification + ML + physics” 思路。

## 7.1 核心术语速记

|术语|简明解释|
|---|---|
|STEM|扫描透射电子显微镜，用聚焦电子束逐点扫描样品成像|

|4D-STEM|每个扫描位置记录一张二维衍射图，形成四维数据|
|Ptychography|利用扫描衍射图重建相位/振幅，提高信息利用率|

|PCA|主成分分析，用于降噪和降维，但可能误删局部缺陷信号|

|CNN|卷积神经网络，适合图像识别、分割、缺陷检测|
|VAE|变分自编码器，用于无监督学习低维结构表征|
|rVAE|rotation-invariant VAE，剥离旋转等因素，学习结构变化|
|Bayesian optimization|贝叶斯优化，用于自动调参和主动实验|
|Reinforcement learning|强化学习，用于显微镜控制和实验策略学习|
|FAIR data|数据要可发现、可访问、可互操作、可复用|

## 7.3 研究脉络时间线

|阶段|研究特点|代表性任务|
|---|---|---|
|阶段 1：人工看图|显微图像主要作为证据展示|看原子、看缺陷|
|阶段 2：定量 STEM|从图像中提取原子坐标、强度、形状|原子定位、强度定量|
|阶段 3：统计分析|PCA、NMF 处理谱图和高维数据|EELS/EDS 降噪、成分分解|
|阶段 4：深度学习|CNN / U-Net 自动识别图像结构|原子分割、缺陷检测、去噪|
|阶段 5：物理机器学习|将图像结果连接到 DFT、相场、格点模型|学习序参量、相互作用、缺陷演化|
|阶段 6：自动化实验|显微镜实时分析、自动调参、主动采样|self-driving microscope、原子级操控|

# 一句话总结

这篇综述的核心不是“机器学习怎么处理 STEM 图片”，而是：

> **STEM 正在从原子图像观察工具，变成原子尺度定量测量与自动实验平台；机器学习的真正价值，是把图像、谱图、衍射和物理模型连接起来，形成可复现、可解释、可自动优化的材料研究流程。**

对你来说，最值得抓住的一条线是：

> **TEM/STEM 图像质量评价不要只看图像指标，而要看它对原子定位、晶格测量、图结构构建和缺陷识别的影响。**
