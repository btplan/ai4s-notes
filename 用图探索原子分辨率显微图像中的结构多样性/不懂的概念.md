
| 文件夹                                    | 中文解释                                                                                                                                                                                                                                                                                                                                                                                                              | 在训练/复现里怎么用                                                                                                                                                                                                                                                                     |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `image`                                | **原始输入图像**。这是模型看到的“带噪声、带背景、带扫描扰动”的合成 ADF-STEM 图像。                                                                                                                                                                                                                                                                                                                                                                 | 作为输入 `X`。你训练 AtomSegNet 或自己做图像质量实验时，主要从这里读图。                                                                                                                                                                                                                                   |
| `gaussianMask`                         | **原子柱高斯标签图**。每个原子柱中心被画成一个高斯峰。论文表 2 说它用于 atomic-column Gaussian mapping，Gaussian 的 FWHM 是 0.2 Å。([Nature](https://www.nature.com/articles/s41598-021-84499-w/tables/2 "Table 2 Description of ground truth labels."))                                                                                                                                                                                              | 最适合你现在的工作。它可以训练模型输出 Gaussian map，然后用 Otsu + 连通域质心提取原子坐标。你之前用的 `gaussianMask+` 模型就是这一类思想。                                                                                                                                                                                       |
| `circularMask`                         | **原子柱圆形分割标签图**。每个原子柱被画成一个圆形 mask，半径由 `radius` 标签决定。([Nature](https://www.nature.com/articles/s41598-021-84499-w/tables/2 "Table 2 Description of ground truth labels."))                                                                                                                                                                                                                                          | 用于训练“原子柱分割”模型。输出更像二值分割图，不是高斯热图。                                                                                                                                                                                                                                                |
| `smallcircularMask`                    | **小半径圆形分割标签图**。也是原子柱 segmentation label，但半径使用 `smallradius`。论文表 2 说 `smallradius` 是正常半径的 70%。([Nature](https://www.nature.com/articles/s41598-021-84499-w/tables/2 "Table 2 Description of ground truth labels."))                                                                                                                                                                                                | 比 `circularMask` 更保守，适合减少相邻原子柱 mask 粘连。                                                                                                                                                                                                                                        |
| `noNoise`                              | **去噪目标图**。意思是没有 noise 的图像，但仍可能保留背景。论文表 2 说它用于 denoising。([Nature](https://www.nature.com/articles/s41598-021-84499-w/tables/2 "Table 2 Description of ground truth labels."))                                                                                                                                                                                                                                     | 训练“输入带噪图 → 输出去噪图”的模型。                                                                                                                                                                                                                                                          |
| `noBackgroundnoNoise`                  | **去噪 + 去背景目标图**。论文表 2 中写作 `noBackgrounnoNoise`，含义是没有噪声、没有背景，用于 denoising and background removal。([Nature](https://www.nature.com/articles/s41598-021-84499-w/tables/2 "Table 2 Description of ground truth labels."))                                                                                                                                                                                             | 训练“输入脏图 → 输出干净无背景图”。这个对图像增强有用，但不一定直接等于原子定位。                                                                                                                                                                                                                                    |
| `noNoiseNoBackgroundSuperresolution`   | **保留强度的超分辨/去模糊标签图**。论文表 2 说它是 Gaussian-type、无噪声、无背景、用于 superresolution / denoising / background removal。([Nature](https://www.nature.com/articles/s41598-021-84499-w/tables/2 "Table 2 Description of ground truth labels."))                                                                                                                                                                                     | 用于训练 deblur / super-resolution 模型。和 `gaussianMask` 不同：它更强调保留原子柱强度差异。                                                                                                                                                                                                           |
| `noNoiseNoBackgroundUpinterpolation2x` | **无噪声、无背景、2×上采样图**。论文表 2 说它有 4× more pixels，用于 upinterpolation、denoising、background removal。([Nature](https://www.nature.com/articles/s41598-021-84499-w/tables/2 "Table 2 Description of ground truth labels."))                                                                                                                                                                                                 | 用于训练 2× 插值/超分模型。注意 2× 宽高意味着总像素数 4 倍。                                                                                                                                                                                                                                           |
| `noNoiseUpinterpolation2x`             | **无噪声、2×上采样图**。但不一定去背景。论文表 2 说它用于 upinterpolation and denoising。([Nature](https://www.nature.com/articles/s41598-021-84499-w/tables/2 "Table 2 Description of ground truth labels."))                                                                                                                                                                                                                             | 用于训练“去噪 + 放大”的模型，比上一个保留更多背景信息。                                                                                                                                                                                                                                                 |
| `position`                             | **原子柱中心坐标标签**。每行是一个原子柱的 `(x, y)`。论文表 2 明确说它是每个 atomic column 的 `(x, y)` positions。([Nature](https://www.nature.com/articles/s41598-021-84499-w/tables/2 "Table 2 Description of ground truth labels."))                                                                                                                                                                                                           | 做定位评估最关键。比如 `position/00001.txt` 里每行就是一个原子坐标。([GitHub](https://github.com/xinhuolin/TEM-ImageNet-v1.3/blob/master/position/00001.txt "TEM-ImageNet-v1.3/position/00001.txt at master · xinhuolin/TEM-ImageNet-v1.3 · GitHub"))                                                 |
| `positionRadius`                       | **原子柱中心 + 半径标签**。每行是 `(x, y, r)`。论文表 2 也明确说明它是 `(x, y, r)` positions and radius。([Nature](https://www.nature.com/articles/s41598-021-84499-w/tables/2 "Table 2 Description of ground truth labels."))                                                                                                                                                                                                             | 如果你要生成圆形 mask、box、region proposal，或者做检测任务，这个比 `position` 更有用。示例文件中每行确实是 x、y、r 三列。([GitHub](https://github.com/xinhuolin/TEM-ImageNet-v1.3/blob/master/positionRadius/00001.txt "TEM-ImageNet-v1.3/positionRadius/00001.txt at master · xinhuolin/TEM-ImageNet-v1.3 · GitHub")) |
| `radius`                               | **每张图对应的圆形 mask 半径**。论文表 2 给出半径公式，和电子波长、收敛角、source size 等有关。([Nature](https://www.nature.com/articles/s41598-021-84499-w/tables/2 "Table 2 Description of ground truth labels."))                                                                                                                                                                                                                                 | 用于解释/重建 `circularMask`。示例 `radius/00001.txt` 只有一个半径值。([GitHub](https://github.com/xinhuolin/TEM-ImageNet-v1.3/blob/master/radius/00001.txt "TEM-ImageNet-v1.3/radius/00001.txt at master · xinhuolin/TEM-ImageNet-v1.3 · GitHub"))                                             |
| `smallradius`                          | **小圆 mask 半径**。论文表 2 说它是上述 `radius` 的 70%。([Nature](https://www.nature.com/articles/s41598-021-84499-w/tables/2 "Table 2 Description of ground truth labels."))                                                                                                                                                                                                                                                   | 用于解释/重建 `smallcircularMask`。                                                                                                                                                                                                                                                   |
| `params`                               | **每张模拟图的成像/生成参数**。官网说数据集提供每张 synthetic image 的 atomic coordinates 和 imaging condition 以便复现。([Google Sites](https://sites.google.com/view/temimagenet/home "TEM ImageNet")) `params/00001.txt` 里是 13 行数值，应该对应模拟时的尺度、噪声、扫描/背景/成像条件等参数。([GitHub](https://github.com/xinhuolin/TEM-ImageNet-v1.3/blob/master/params/00001.txt "TEM-ImageNet-v1.3/params/00001.txt at master · xinhuolin/TEM-ImageNet-v1.3 · GitHub")) | 做严肃复现实验时很重要：你可以把它理解为每张图的“实验条件说明书”。但仓库 README 没有逐行解释，所以不要随便乱命名每一行参数。                                                                                                                                                                                                            |
| `misc`                                 | **杂项文件夹**。仓库里有这个目录，但公开页面没有给清晰说明。([GitHub](https://github.com/xinhuolin/TEM-ImageNet-v1.3 "GitHub - xinhuolin/TEM-ImageNet-v1.3: TEM-ImageNet · GitHub"))                                                                                                                                                                                                                                                          | 先不用作为主线。真正做训练/评估时，优先看 `image`、`gaussianMask`、`position`、`params`。                                                                                                                                                                                                              |
