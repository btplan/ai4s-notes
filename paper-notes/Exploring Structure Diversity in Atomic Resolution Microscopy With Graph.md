## 0. 翻译摘要原文

深度学习的出现为原子分辨显微图像的高通量分析提供了重要机会。然而，基于固定尺寸图像块训练的深度学习模型，在处理包含多样化原子构型的显微图像时，通常缺乏效率和灵活性。

本文受原子结构与图结构相似性的启发，提出了一种基于等变图神经网络（EGNN）的少样本学习框架，用于分析原子结构库，例如空位、相结构、晶界和掺杂等。与图像驱动的深度学习模型相比，该方法显著提高了鲁棒性，并将计算参数量降低约三个数量级；这一优势在识别具有柔性晶格畸变的聚集空位线时尤其明显。

此外，图结构的直观性使得模型能够批量、定量、直接地提取原子尺度结构特征，从而统计揭示电子束照射下空位线的自组装动力学。作者进一步将多个针对单一结构识别的 EGNN 子模型整合成任务链，建立了一个通用模型工具箱，用于处理包含多种原子构型的图像，并发现了具有优异析氢反应电催化性能的新型掺杂构型。本文提供了一种快速、准确、智能地探索原子结构多样性的有力工具。

## 1. 方法动机

### 1.a 作者为什么提出这个方法？背后的驱动力是什么？

作者的出发点是：原子分辨 TEM/STEM 图像中，真正决定材料性质的不是整张图像的所有像素，而是原子柱的位置、相邻关系、局部灰度和空间排布。材料性质由原子及其空间排列决定，而现代 TEM 已经可以以皮米级精度直接观察这些原子结构。因此，显微图像分析的核心目标应从“看图”转向“把图像转化为可计算、可统计、可解释的原子结构”。

传统人工分析流程大致是：先找原子柱，再判断局部配位环境，最后结合亮度和几何关系识别空位、晶界、堆垛或掺杂。这个流程和图神经网络非常相似：原子是节点，相邻关系是边，灰度和坐标是节点特征，局部结构类别是分类目标。作者因此提出用图来表示原子分辨图像，用 EGNN 来学习原子结构。

背后的驱动力有三点：

1. 原子尺度结构类型多样，人工识别工作量大且带有主观性。
2. 真实 TEM 图像中结构常常不是规则 patch，而是晶界、空位线、堆垛边界等不规则局部几何。
3. 固定像素窗口的 CNN 会处理大量真空或背景像素，计算冗余大，少样本下容易过拟合。

### 1.b 现有方法的痛点/不足是什么？

主要痛点有四类。

第一，人工分析效率低。  
空位、晶界、相界、堆垛、掺杂这些结构需要结合局部亮度和空间关系判断，高通量图像或动态视频不适合人工逐点标注。

第二，模拟训练数据难覆盖复杂结构。  
简单点缺陷或掺杂可以用模拟数据生成标签，但复杂晶界、聚集空位线、柔性晶格畸变等结构很难批量合成。实验 TEM 图像虽然真实，但人工标注成本高。

第三，固定图像块 CNN 缺乏几何灵活性。  
CNN 通常裁剪固定尺寸 image patch。对规则结构可行，但对空位线、晶界等不规则结构，固定窗口要么包含大量无关像素，要么截断结构上下文，导致过拟合和效率低。

第四，普通 GNN 没有充分利用几何等变性。  
普通 GNN 主要看节点特征和邻接关系，但原子结构还强烈依赖坐标、距离、方向、旋转和局部畸变。因此作者进一步采用 EGNN，让模型显式学习空间坐标变化。

### 1.c 论文的研究假设或直觉是什么？

核心直觉是：

> 原子分辨图像天然是图，原子结构识别应围绕“点、边、几何关系”展开，而不是围绕固定像素块展开。

更具体地说：

> 如果先把 TEM 图像转成原子图，再让模型在局部邻接关系中学习结构类别，就能用更少样本、更少参数、更高效率识别复杂原子构型。

## 2. 方法设计

### 2.a 方法流程总结：输入 → 处理 → 输出

这篇论文的方法可以拆成七步。

**Step 1：输入原始 ADF-STEM / HR-TEM 图像**

输入是原子分辨显微图像。主要案例包括 MoS2 的 ADF-STEM 图像、电子束照射后的 HR-TEM 图像，以及 Pt 掺杂 MoS2 图像。图像中亮斑对应原子柱，灰度携带元素或原子柱组成信息。

**Step 2：用 multi-scale U-Net 定位原子柱**

作者先用 multi-scale U-Net 对图像做像素级预测，输出原子概率图。这个 U-Net 不是普通单尺度 U-Net，而是在不同分辨率分支上同时产生预测，从而捕捉多尺度图像特征。

输入：原始图像。  
输出：原子柱概率图。  
作用：把连续图像变成“哪里可能是原子”的概率分布。

训练时使用 Dice loss + cross entropy loss；推理时只使用最高分辨率概率图。

**Step 3：Otsu 二值化 + 圆霍夫变换得到原子中心**

U-Net 输出概率图后，作者用 Otsu algorithm 自动选择阈值，将概率图分成前景和背景。然后用 circular Hough transform 把前景区域拟合为圆形对象，圆心被定义为原子柱中心。

输入：概率图。  
处理：Otsu 阈值分割 → circular Hough transform。  
输出：原子中心坐标集合。  
结果：原子定位 F1 score 达到 99.8%，即使存在像散或表面污染也能保持较好定位。

这一步非常重要，因为后续所有图结构都依赖原子点是否准确。

**Step 4：用 Delaunay triangulation 构建原子平面图**

有了原子中心点后，作者用 Delaunay 三角剖分自动连接相邻原子。Delaunay 用于生成候选邻接边，但不是所有边都保留。

作者进一步设置边长阈值：  
如果某条边超过根据晶格参数设定的长度阈值，就删除。这样可以避免把远距离、不应相邻的原子错误连接起来。

输入：原子坐标点。  
处理：Delaunay 三角剖分 → 长边过滤。  
输出：原子图结构，包括节点、边和邻接矩阵。

这一步把“图像里的亮点”转成“晶体中的原子连接关系”。

**Step 5：提取局部图样本**

作者不是直接把整张大图输入 EGNN，而是以每个检测到的原子为中心，搜索一阶或二阶近邻，提取局部 graph sample。

对于堆垛结构识别，主要搜索一阶近邻。  
对于空位线识别，作者使用二阶近邻，因为空位是否聚集成线需要更大局部上下文。

每个 graph sample 包含：

1. 中心节点；
2. 周围邻居节点；
3. 节点之间的边；
4. 节点坐标；
5. 节点局部灰度特征。

这样做的关键优势是：图样本大小和形状随真实原子结构变化，而不是被固定像素窗口限制。

**Step 6：为每个节点构造特征**

每个节点有两类信息。

第一类是局部灰度特征。  
作者为每个节点分配 flattened 9D feature，来自对应原子柱附近的局部灰度信息。这个特征包含原子柱亮度和可能的组成信息。

第二类是平面坐标。  
作者以图样本中心为原点，提取每个节点的相对坐标。坐标用于告诉模型节点之间的距离、方向和空间排列。

所以 EGNN 的输入不是单纯灰度，也不是单纯邻接矩阵，而是：

> 邻接关系 + 节点灰度特征 + 节点空间坐标

**Step 7：用 EGNN 做节点分类或图分类**

EGNN 接收三类输入：

1. 邻接矩阵 E；
2. 节点特征 h；
3. 节点坐标 x。

模型通过 EGCL 层同时更新节点特征和坐标表示。每一层中，节点会从邻居节点聚合信息，同时利用两点之间的距离和相对位置更新表示。

输出有两种模式：

第一，中心原子分类。  
例如判断中心节点是 Mo、2S，还是 S vacancy。

第二，局部图结构分类。  
例如判断整个局部图样本属于 1H、2H、3R、正常晶格、点空位、空位线、晶界或掺杂构型。

最终通过 Softmax 输出类别概率。

**Step 8：将多个 EGNN 子模型组合成任务链**

对于复杂图像，一个模型不够。真实 Pt 掺杂 MoS2 图像中可能同时有 Pt 掺杂、晶界、堆垛结构、硫空位。作者因此训练多个专门子模型：

1. 掺杂识别模型；
2. 堆垛构型识别模型；
3. 晶界识别模型；
4. 空位识别模型。

然后按任务链顺序依次执行，并把多个模型输出叠加，最终识别复合构型，例如 Pt@GB8@Sv。

这个任务链思想很重要：作者不是试图训练一个万能大模型，而是把多个小模型组合起来处理复杂结构。

### 2.b 模型结构：每个模块的功能与协同方式

| 模块 | 功能 | 输出 | 在整体方法中的作用 |
|---|---|---|---|
| Multi-scale U-Net | 原子柱像素级分割 | 原子概率图 | 负责从图像中找点 |
| Otsu | 自动阈值分割 | 前景/背景二值图 | 将概率图变成候选原子区域 |
| Circular Hough Transform | 圆心检测 | 原子中心坐标 | 得到精确节点坐标 |
| Delaunay triangulation | 构建邻接关系 | 原子图边 | 建立晶体近邻连接 |
| Edge threshold | 删除过长边 | 清洁图结构 | 避免错误邻接污染 |
| Graph sampler | 提取局部邻域 | 一阶/二阶图样本 | 生成 EGNN 输入样本 |
| Node embedding | 加入灰度与坐标 | 9D 灰度特征 + 坐标 | 提供组成和几何信息 |
| EGNN | 图特征聚合与分类 | 节点/图类别概率 | 识别结构类型 |
| Task chain | 组合多个子模型 | 复合结构识别结果 | 分析真实复杂图像 |

协同逻辑是：

> U-Net 找原子点，Delaunay 建连接，graph sampler 取局部结构，EGNN 判断结构类别，task chain 组合多种结构识别结果。

### 2.c 公式/算法的通俗解释

**Multi-scale U-Net 公式**

论文把输入图像记为 `p`，multi-scale U-Net 输出四个尺度的概率图：

> v0, v1, v2, v3

可以理解为：模型从原图、1/2 尺度、1/4 尺度、1/8 尺度同时看原子特征。训练时多个尺度共同帮助模型学习；推理时使用最高分辨率 `v0` 做原子定位。

**Otsu + CHT 公式**

论文表示为：

> x0 = CHT(OTSU(v0))

意思是：先对概率图 `v0` 做 Otsu 二值化，再用圆霍夫变换找圆心，得到所有原子中心坐标。

**EGNN 消息传递公式**

EGNN 中每条边的信息 `mij` 由三个东西决定：

1. 节点 i 的特征；
2. 节点 j 的特征；
3. 两个节点之间的距离。

通俗理解：

> 模型判断两个原子之间的关系时，不只看它们各自亮不亮，还看它们离多远。

随后每个节点更新坐标表示和特征表示。这样模型可以学习“这个局部结构如何随旋转一起变化”，而不是把旋转后的同一结构误认为不同类别。

**中心节点分类公式**

如果任务是判断中心原子类别，就对中心节点最终特征做 Softmax。

**图分类公式**

如果任务是判断整个局部结构类别，就先聚合所有节点特征，再做 Softmax。

**损失函数**

U-Net 阶段：Dice loss + cross entropy。  
Dice loss 适合类别不平衡的分割任务，cross entropy 衡量像素分类是否正确。  
EGNN 阶段：cross entropy，用于结构类别分类。

**评价指标**

主要用 precision、recall、F1 score。F1 适合类别不均衡场景，因为缺陷样本通常远少于正常原子。

## 3. 与其他方法对比

### 3.a 本方法和现有主流方法相比有什么本质不同？

本质不同在于：它从“图像块识别”转向“原子图识别”。

CNN / ResNet / YOLO 的基本单位是像素块或检测框。它们处理的是固定网格图像，容易把真空、背景、无关像素也纳入计算。

本文方法的基本单位是原子图。它只保留原子节点、边、灰度、坐标这些和晶体结构直接相关的信息，因此更接近材料结构本身。

可以概括为：

> CNN 看固定窗口里的像素模式；EGNN 看原子之间的几何关系。

### 3.b 创新点在哪里？贡献度如何？

**创新点 1：将原子分辨图像系统转化为原子图结构。**  
贡献度高。这是全文最核心思想，直接改变了 TEM 图像分析的数据表示方式。

**创新点 2：用 EGNN 引入旋转等变和空间坐标学习。**  
贡献度高。普通 GNN 只用邻接关系和节点特征，EGNN 进一步利用坐标和相对几何，对晶格旋转、局部畸变、空位线更鲁棒。

**创新点 3：少样本学习复杂原子构型。**  
贡献度高。堆垛识别中每类约 200 个 graph samples 就能训练，显著缓解实验图像标注困难。

**创新点 4：从分类结果直接提取材料统计量。**  
贡献度中高。作者不仅给出结构标签，还统计空位浓度、配位数、混合度，用于解释空位线自组装过程。

**创新点 5：任务链式模型工具箱。**  
贡献度高。多个 EGNN 子模型组合后，可以发现复合构型，如 Pt@GB8@Sv，并连接到 DFT 计算和催化性能。

### 3.c 在什么场景下更适用？

最适合的场景：

1. 原子位置可被较准确检测的 ADF-STEM / HR-TEM 图像；
2. 局部结构由原子几何关系决定；
3. 训练样本少，但结构有明确物理定义；
4. 存在晶界、堆垛、空位线、掺杂等局部复杂结构；
5. 需要批量统计结构特征，而不只是分类准确率；
6. 需要将图像识别结果接到 DFT 或材料机制分析。

不太适合的场景：

1. 原子定位本身严重失败；
2. 图像信噪比太低，无法构建可靠节点；
3. 材料结构没有清晰近邻关系；
4. 缺少必要结构标签；
5. 三维投影重叠严重，二维图结构不足以表达真实结构。

### 3.d 方法对比表

| 方法 | 优点 | 缺点 | 本文改进点 |
|---|---|---|---|
| 人工分析 | 物理直觉强，可解释 | 慢、主观、难高通量 | 自动化识别和统计 |
| 传统图像处理 | 简单、无需大量训练 | 对复杂畸变和多结构不鲁棒 | 用图结构表达近邻关系 |
| CNN / ResNet | 图像特征提取能力强 | 固定 patch、参数多、少样本易过拟合 | 用图样本减少冗余像素 |
| YOLO | 适合目标检测 | 不适合精细局部结构分类 | EGNN 直接看原子邻接结构 |
| Zernike polynomial | 可描述局部形状 | 对复杂空位线表现不足 | EGNN 同时利用灰度、邻接和坐标 |
| 普通 GNN | 能处理图结构 | 几何坐标利用不足 | EGNN 加入空间坐标和旋转等变 |
| 本文 EGNN | 少样本、高效、可解释、适合畸变结构 | 依赖前端原子定位和构图质量 | 将 TEM 图像推进到原子结构理解 |

## 4. 实验表现与优势

### 4.a 作者如何验证方法有效性？

作者用了四类实验验证。

**实验 1：MoS2 中 Mo、2S、S vacancy 识别**

这是方法展示案例。作者先用 multi-scale U-Net 找原子点，再构图，再提取局部 graph samples，最后用 EGNN 做节点分类，识别 Mo 原子柱、2S 原子柱和 S vacancy。

**实验 2：多材料边界和界面识别**

作者验证方法可扩展到不同材料和结构：

1. MoS2 中 2H-3R 堆垛边界；
2. MoS2 晶界；
3. NCM811 中 O3 和 rock-salt phase 相界；
4. Al/Si 异质界面。

**实验 3：MoS2 中 1H、2H、3R 堆垛构型分类**

作者以 MoS2 横向异质结构为例，每种构型约 200 个 graph samples，来自两张 ADF-STEM 图像。比较 EGNN 和 CNN/ResNet 18 的训练验证损失、F1 和推理效率。

**实验 4：电子束诱导 S 空位线动态演化**

作者用 0 s 电子束照射样品的一张 HR-TEM 图像训练 EGNN，用 10 s、20 s、30 s、40 s 图像测试。目标是区分正常结构、离散点空位、聚集空位线，并进一步统计空位浓度、配位数、混合度。

**实验 5：Pt 掺杂 MoS2 复合结构发现**

作者将多个 EGNN 子模型组合成任务链，分析 Pt 掺杂缺陷 MoS2 图像，识别 Pt 掺杂、堆垛、晶界、空位，发现 Pt@GB8、Pt@GB4、Pt@Sv、Pt@GB8@Sv 等构型，并用图像模拟和 DFT 解释催化潜力。

| 任务 | 关键结果 |
|---|---|
| 原子定位 | multi-scale U-Net + Otsu + CHT 原子定位 F1 score = 99.8% |
| 堆垛分类 | EGNN F1 > 0.98；CNN F1 = 0.60 |
| 训练/验证差距 | EGNN training-validation loss MSE = 0.019；CNN = 0.341，说明 CNN 过拟合更明显 |
| 参数量 | 图学习相比图像模型参数量减少近 8000 倍 |
| 推理效率 | 堆垛识别中 EGNN 推理效率提升 3.9 倍 |
| 空位线识别 | 聚集空位线 F1 = 97.6%；离散点空位 F1 = 97.5% |
| ResNet 对比 | line vacancy F1 = 92.5%；point vacancy F1 = 84.7% |
| Zernike 对比 | line vacancy F1 = 85.7%；point vacancy F1 = 51.1% |
| 40 s 动态图像 | 聚集空位线 F1 = 98.3%；离散空位 F1 = 87.3% |
| 单图计算时间 | 超过 5000 个 graph samples 时，一张图端到端计算 0.56 s，比 CNN 快 5.5 倍 |
| 动态统计 | S vacancy 浓度从初始约 6% 增至 40 s 后近 15% |
| 催化构型 | Pt@GB8@Sv 的 ΔGH = -0.20 eV，接近 0，更有利于 HER |

### 4.c 哪些场景下优势最明显？

优势最明显的是具有柔性晶格畸变的空位线识别。

原因是：空位线长度、宽度和形状变化大，局部晶格畸变可达 20.8%。固定 patch 模型难以确定合适窗口，YOLO、U-Net、ResNet、Zernike 都会不同程度失效。而图样本可以沿真实原子连接关系扩展，EGNN 还能利用坐标判断空位是否聚集成线。

第二个明显优势是少样本堆垛结构识别。每类约 200 个 graph samples 即可训练，EGNN F1 超过 0.98，而 CNN 只有 0.60，并且明显过拟合。

第三个优势是动态 TEM 图像。电子束照射时间增加后，结构越来越畸变，但 EGNN 仍能保持较高识别性能，并能在 0.56 s 内处理一张图，适合动态结构分析。

### 4.d 局限性

第一，强依赖原子定位质量。  
前端 U-Net + Otsu + CHT 如果漏检或误检，后续图结构会被污染。论文报告原子定位 F1 很高，但这是在其数据和预处理条件下得到的。

第二，Delaunay 边长阈值需要按晶格参数设定。  
如果材料晶格复杂、多相重叠或畸变极强，边长阈值不容易泛化。

第三，仍需要结构标签。  
EGNN 是监督学习框架。虽然少样本，但仍然需要每类结构的标注 graph samples。

第四，二维图表示可能不足以处理复杂三维投影。  
TEM 图像是 3D 结构的 2D 投影，重叠原子柱、厚样品、动力学散射可能导致单纯二维图不够。

第五，任务链依赖子模型质量。  
多个模型叠加可以发现复合构型，但也可能累积错误。一个子模型误识别，后续复合构型判断会受影响。

第六，完整复现成本不低。  
虽然代码和数据公开，但要完整复现 Figure 5 还需要图像模拟、DFT、结构建模和催化自由能计算。

## 5. 学习与应用

### 5.a 是否开源？如何复现？

论文声明所有数据和代码可在 GitHub 获取：

> https://github.com/Zi-Jian-Gao/Exploring-structure-diversity-in-atomic-resolution-microscopy-with-graphs

如果你想复现，建议不要一开始复现全文，而是分三层。

**最小复现 1：图像到图结构**

1. 读入一张原子分辨图像；
2. 用已有原子定位方法得到原子点；
3. 用 Delaunay triangulation 构图；
4. 设置边长阈值删除长边；
5. 提取一阶/二阶邻居图样本；
6. 可视化节点、边、局部图样本。

这一层不用训练 EGNN，先理解图如何构建。

**最小复现 2：三分类结构识别**

1. 准备 normal / point vacancy / line vacancy 三类局部图样本；
2. 每个节点输入局部灰度 9D feature 和相对坐标；
3. 训练两层 EGNN；
4. 比较有无坐标输入的效果；
5. 用 F1 评价分类结果。

**最小复现 3：图结构质量评价**

结合你的研究，可以不直接复现催化部分，而是做：

1. 原图、加噪图、模糊图、低对比度图；
2. 分别做原子定位和构图；
3. 比较节点数、边数、配位数、异常长边比例、局部图分类稳定性；
4. 将这些作为 TEM 图像质量指标。

### 5.b 超参数、预处理、训练细节

论文中可复用的关键设置：

| 项目 | 设置 |
|---|---|
| 图像平滑 | ImageJ Gaussian blur，σ = 3 |
| 原子定位训练集 | 10 张不同尺寸 labeled (S)TEM 图像 |
| 原子定位验证集 | 3 张 labeled (S)TEM 图像 |
| EGNN 训练 | 每个具体任务只用 1 张 labeled 图像训练、1 张验证，其余测试 |
| U-Net 数据增强 | 翻转、Gaussian blur、亮度/对比度调整、平移、缩放、旋转 |
| EGNN 层数 | 2 层 |
| 输入/隐藏节点维度 | 9 / 6 |
| 优化器 | AdamW |
| batch size | 32 |
| 学习率调度 | ReduceLROnPlateau |
| early stopping | 验证指标连续 2 个 epoch 不提升则停止 |
| 最大 epoch | 1000 |
| EGNN 损失 | cross entropy |
| U-Net 损失 | Dice loss + cross entropy |
| 评价指标 | precision、recall、F1 score |

实现建议：

1. 先不要追求端到端，先把“原子坐标 → Delaunay 图 → graph sample”跑通。
2. 边长阈值一定要根据晶格常数调，否则图会过连或断连。
3. 坐标建议用中心节点为原点的相对坐标，减少平移影响。
4. 灰度特征要做归一化，否则不同图像亮度差异会污染节点特征。
5. 做消融时必须比较“灰度 + 坐标 + 邻接”和“灰度 + 邻接”，因为空间坐标是 EGNN 优势来源。
6. 如果用于图像质量评价，要固定模型和构图参数，只改变输入图像质量，否则指标不可比。

### 5.c 能否迁移到其他任务？如何迁移？

可以迁移，而且非常适合你的 TEM 图像方向。

**迁移 1：TEM 图像质量评价**

把图像质量定义为：

> 图像能否稳定地产生合理原子图结构。

可迁移指标：

1. 原子数稳定性；
2. Delaunay 边数稳定性；
3. 配位数分布稳定性；
4. 异常长边比例；
5. 局部晶格边长标准差；
6. 图分类结果稳定性；
7. 缺陷识别 F1 随退化强度的下降曲线。

**迁移 2：AtomSegNet 后处理**

AtomSegNet 输出原子坐标后，可以接本文方法：

> AtomSegNet → 原子点 → Delaunay graph → EGNN → 结构一致性评价

这样可以把 AtomSegNet 从“定位模型”扩展成“结构分析模型”。

**迁移 3：缺陷识别**

适合识别 vacancy、dopant、grain boundary、phase boundary、stacking fault 等，只要这些结构能用局部原子图表达。

**迁移 4：动态 TEM 视频**

对每一帧构图并分类，再统计缺陷浓度、配位数、聚集程度，就能分析电子束诱导结构演化。

**迁移 5：多模型任务链**

可以为不同结构训练小模型，然后组合：

> 原子类型识别 → 缺陷识别 → 晶界识别 → 掺杂环境识别 → 复合构型统计

这对真实复杂材料图像比训练一个大模型更现实。

## 6. 总结

### 6.a 一句话概括核心思想

**把原子图像变成原子图。**

### 6.b 速记版 pipeline

> 找出所有原子点 → 按晶格邻近关系连线 → 围绕每个原子取邻居小图 → 给每个点加入亮度和坐标 → 让模型判断这个小结构属于哪一类 → 把所有小结构结果拼回整张图 → 统计缺陷和结构演化。

### 6.c 和你已经阅读过的文献有什么联系？

**和 TEMImageNet / AtomSegNet 的关系**

AtomSegNet 解决的是：

> 图像 → 原子分割 / Gaussian map / 原子定位

本文解决的是：

> 原子定位 → 原子图结构 → 局部结构识别

所以本文可以看作 AtomSegNet 的下游扩展。AtomSegNet 告诉你原子在哪里；这篇文章告诉你这些原子构成什么结构。

对你的研究来说，二者可以合成一条质量评价路线：

> 输入图像质量变化 → AtomSegNet 定位结果变化 → 原子图结构变化 → EGNN 结构识别变化

这比单独看定位误差更接近材料分析需求。

**和 ELIT 的关系**

ELIT 关注的是模型在真实实验图像中的可靠性和不确定性：

> 哪些原子定位可信？哪些区域不确定？

本文则关注可靠原子点之后的结构理解：

> 这些原子点组成了什么结构？结构如何演化？是否影响材料性质？

所以 ELIT 可以作为本文方法的上游质量控制模块。先用 ELIT 过滤不可靠原子点，再构建图结构，会比直接构图更稳健。

**和 Machine Learning in STEM 综述的关系**

综述强调 STEM + ML 的趋势是：

> 定量结构提取 → 物理解释 → 自动实验

本文正好是这一思路的具体实现：从图像中自动提取原子结构，统计空位演化，并用 DFT 连接催化性能。

**和你自己的 TEM 图像质量评价方向的关系**

这篇文章给你的最大启发是：

> 图像质量不应只评价像素清晰度，而应评价它能否支持稳定的原子图结构和下游缺陷识别。

你可以把论文方法转化成自己的评价框架：

1. 固定原子定位模型；
2. 对不同退化图像构建原子图；
3. 比较节点、边、配位数、局部图分类是否稳定；
4. 用结构稳定性评价 TEM 图像质量；
5. 最后连接缺陷识别或材料机制分析。
